## 🌟 Key Features

* **👁️ Real-Time OCR Screen Scanning:** Automatically reads droid names, metal variants (Gold, Beskar, Rainbow, Galactic), and rarity tiers as soon as they spawn.
* **⏱️ Guaranteed Drop Countdowns & HUD Cards:** Displays sleek, customizable top-of-screen countdown timers for Beskar, Mythic, and Galactic drops right over your game window.
* **🗣️ Voice & Audio Alerts:** Reads matched spawns out loud using crystal-clear neural cloud voices or alerts you with custom telemetry audio chimes.
* **🎯 Custom Target List Builder:** Build a personalized checklist to monitor *only* the specific droids and metal finishes you still need.
* **📐 Interactive Visual Bounding Zones:** Draw custom screen tracking boxes over your game window with live diagnostic OCR feeds.
* **📢 Discord Webhook Integration:** Beam instant spawn notifications straight into your private Discord channels.
* **🚀 Instant One-Click Updates:** Built-in auto-updater keeps your app running on the latest build automatically without needing manual re-downloads.
